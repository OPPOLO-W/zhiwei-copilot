# 如何使用区域/家居/自定义清洁/省心模式？

**一：省心模式使用**

1. 进入智能清洁-选择省心模式

2. 地图建立成功后，才可以使用

① 省心模式下机器会根据房间类型，自主调节吸力等工作。

**二：区域清洁使用**

1. 地图建立成功后，才可以使用。

2. 地图首次建图成功后，机器将会自动分区。

3. 根据实际需要，选择相应区域进行打扫，可在“清洁偏好”选择清洁模式（如扫地）清洁次数，吸力大小，水量调节。

4. 选择多个区域打扫，地宝会根据选择的清扫顺序，依次进行打扫（仅单次生效）

5. 扫地模式下无法调节水量；扫拖模式下无法调节吸力，先扫后拖无法调节清洁次数。

**使用方法：**

① 使用语音助手控制：

您也可以尝试对机器人说：“OK YIKO, 去房间一清扫；OK YIKO, 去房间一和儿童房清扫”

② 使用APP控制：

**注：①若您已在“清洁顺序”中已有设置好清扫顺序，地宝会优先按清扫顺序中所设置的顺序清扫。**

**②若机器已开始工作，清扫次数，清洁模式不可调整；吸力大小，水量调节可按需求实时调整。**

**三：家居清洁使用**

1. 建图完成后并地图上有家具后才可以使用此功能（如无可在-地图-家居装饰中添加）。

2. 根据实际需求可在“清洁偏好”选择清洁模式（如扫地）清洁次数，吸力大小，水量调节。

3. 扫地模式下无法调节水量；扫拖模式下无法调节吸力，先扫后拖无法调节清洁次数。

**四：自定义清洁使用**

1. 地图建立成功后，或有部分地图时，即可使用自定义打扫，且只能在地图范围内进行设定

2. 可在地图范围内添加一个或多个自定义区域，地宝会根据添加的自定义区域，依次进行打扫

3. 根据实际需求可在“清洁偏好”选择清洁模式（如扫地）清洁次数，吸力大小，水量调节。

4. 扫地模式下无法调节水量；扫拖模式下无法调节吸力，先扫后拖无法调节清洁次数。

**注：①若机器已开始工作，清扫次数，清洁模式不可调整；吸力大小，水量调节可按需求实时调整。**

**②自定义区域最多可添加5个，自定义区域大小最小默认为：1m *1m.**
