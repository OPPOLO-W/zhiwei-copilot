# 如何正确安装机器人？

**一：机器人安装**

1. 请打开外包装箱取出主机，配件包装盒，基站；

2. 取下主机盖板，移除主机防撞保护条，基站上的保护海绵装置等。

3. 请将主机翻转后，底部朝上放置。在配件包装盒内取出红绿色边刷，对准卡槽后往下按，听到“嗒”一声表示安装到位。

4. 请在配件包装盒内取出电源线，和基站背面电源接口连接，接通电源，寻找合适位置靠墙摆放。

**（基站放置在平坦的地面，左右**≧**0.05m和前方**≧**0.8m 范围内不要放置物品）**

**温馨提示：**

**基站优先放置瓷砖地面使用，若您放置在地板使用，请定期检查基站底部是否残留水渍，若有请及时清理，以防受潮**
