# 如何正确切换机器人的清洁模式？

**一：机器人清洁模式切换**

**请您先确认机器人已连接网络，并打开ECOVACS HOME app进行相关设置**

**1.进入智能清洁>点击清洁偏好>选择扫地**

您也可以通过OK YIKO 语音助手来让机器执行工作任务

（例：ok yiko 扫地模式下工作即可，若想切换其他工作模式，您需要说:“ ok yiko 结束工作任务”；再次使用可说：“ ok yiko 拖地模式下工作”以此类推）

注：此状态下安装抹布支架也可以使用，工作时抹布为抬升状态。

**2.进入智能清洁>点击清洁偏好>选择拖地**

您也可以通过OK YIKO 语音助手来让机器执行工作任务

（例：ok yiko 扫地模式下工作即可，若想切换其他工作模式，您需要说:“ ok yiko 结束工作任务”；再次使用可说：“ ok yiko 拖地模式下工作”以此类推）

注：此状态下边刷转动，滚刷不转动也不吸灰尘，抹布支架下降并转动，若开启自适应地毯，遇到地毯抹布支架会抬升。

**3.进入智能清洁>点击清洁偏好>选择边扫边拖**

您也可以通过OK YIKO 语音助手来让机器执行工作任务

（例：ok yiko 扫地模式下工作即可，若想切换其他工作模式，您需要说:“ ok yiko 结束工作任务”；再次使用可说：“ ok yiko 拖地模式下工作”以此类推）

注：此状态下机器边扫边拖同时进行工作。

**4.进入智能清洁>点击清洁偏好>选择先扫后拖**

您也可以通过OK YIKO 语音助手来让机器执行工作任务

（例：ok yiko 扫地模式下工作即可，若想切换其他工作模式，您需要说:“ ok yiko 结束工作任务”；再次使用可说：“ ok yiko 拖地模式下工作”以此类推）

注：①此状态下先扫地，抹布支架为抬升状态不转动；

② 清扫完成后再执行拖地，抹布支架下降并转动，边刷转动，滚刷不转动也不吸尘，若开启自适应地毯，遇到地毯抹布支架会抬升

温馨提示：

1. 扫地，拖地，边扫边拖 在清洁前可以设置清洁次数，若设置两次，为横弓，竖弓各清洁一遍。

2. 先扫后拖，无法设置清洁次数，清洁路径一致。

3. 满电到电量低状态；使用标准吸力:

① 单扫模式约180min;

② 边扫边拖约170min；

③ 单拖模式约320min；

（注：此数据为科沃斯实验室数据，因家庭环境复杂，具体以实际您使用为准）

4. YIKO 语音助手需配网成功后才可使用。
